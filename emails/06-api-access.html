Your API key is already on the account page. Call POST /api/service with Bearer auth:

curl -X POST https://manifoldgen.com/api/service \
  -H "Authorization: Bearer YOUR_KEY" \
  -H "Content-Type: application/json" \
  -d '{{"service":"zimage","prompt":"teal orchid greenhouse"}}'
